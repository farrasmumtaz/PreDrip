## Baseline Product Decision

- Produk: PreDrip.
- Platform awal: web application.
- Stack awal: Node.js, Next.js App Router, TypeScript, PostgreSQL.
- Backend awal: Next.js full-stack dengan Server Actions/API route sesuai kebutuhan.
- ORM rekomendasi: Prisma.
- MVP pertama: authentication foundation.
- Auth scope awal: register, login, logout, forgot password, reset password, password hashing, session, role dasar.

## Dokumentasi Berikutnya

Tahap berikutnya adalah PRD. PRD akan menurunkan Business Requirement menjadi:

- persona dan user role,
- scope MVP,
- feature list,
- user stories,
- acceptance criteria,
- edge cases,
- non-functional requirement,
- release milestone.
